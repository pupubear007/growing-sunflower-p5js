🌻 Just built a living, breathing sunflower that grows right in your browser!

I coded this real-time phyllotaxis sunflower using p5.js — it starts as a tiny stem, grows leaves, blooms golden petals, and fills with hundreds of seeds arranged in nature’s perfect spiral (the golden angle ~137.5°).

✨ Features:
• Smooth animated growth + gentle swaying
• Dynamic leaves that appear as the stem rises
• Blooming petals + classic sunflower seed spiral
• Fully interactive controls: seeds (up to 2000), scale, sway, speed
• Pause / Resume + Reset & Grow buttons

Pure single-file HTML + p5.js — no build step, no dependencies beyond the p5 CDN. Just open and watch math meet nature.
